# Morning

Warm morning paper, green-black ink, tinted surfaces that feel like daylight. Built for something opened every day for weeks. It is not a gym poster: no shouting type, no neon.

```css
:root {
  --paper: #faf7f0;
  --paper-2: #ffffff;
  --paper-3: #efeadd;
  --ink: #16241b;
  --ink-2: #304236;
  --muted: #56645a;
  --rule: #e2dccd;
  --accent: #2f7a43;
  --accent-ink: #ffffff;
  --focus: #2f7a43;
  --font-display: 'Bricolage Grotesque', system-ui, sans-serif;
  --font-body: 'Figtree', system-ui, sans-serif;
  --font-data: ui-monospace, monospace;
  --radius-card: 18px;
  --radius-control: 12px;
  --hairline: 1px;
  --shadow: 0 10px 30px -18px rgb(22 36 27 / 30%);
  --display-weight: 700;
  --display-tracking: -0.02em;
}
```

**Type.** Bricolage for headings with character, Figtree for calm body text. Big numbers for today's progress.

**Surfaces.** Rounded cards tinted from the paper, never pure white on white.

**Controls.** Large 48px controls, one filled green action per screen.

**Voice.** Encouraging without cheerleading: "Day 6. Two more glasses".

**Do not.**
- red for a missed day
- streak shaming
- stock fitness models
- more than one celebration per day
