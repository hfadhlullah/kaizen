# Orchid

A soft consumer AI app on pale lilac paper. Lowercase geometric type, hairline pills, and one orchid colour reserved for what the AI made, so the user can always tell their words from the machine's. It is not the purple-to-blue gradient look: flat colour only.

```css
:root {
  --paper: #f7f4fb;
  --paper-2: #ffffff;
  --paper-3: #ece6f4;
  --ink: #1e1726;
  --ink-2: #3d3348;
  --muted: #625a6e;
  --rule: #ddd4ea;
  --accent: #8e2fb8;
  --accent-ink: #ffffff;
  --focus: #8e2fb8;
  --font-display: 'Outfit', system-ui, sans-serif;
  --font-body: 'Outfit', system-ui, sans-serif;
  --font-data: ui-monospace, monospace;
  --radius-card: 16px;
  --radius-control: 999px;
  --hairline: 1px;
  --shadow: 0 12px 32px -16px rgb(60 20 90 / 25%);
  --display-weight: 500;
  --display-tracking: -0.02em;
}
```

**Type.** Outfit lowercase headings at 500. Body 17px at 1.6 for long AI answers.

**Surfaces.** White sheets on lilac, large radius, one soft shadow for the composer.

**Controls.** Pill controls with hairline borders; the send button is the only filled one.

**Voice.** Warm and direct, never cute. The AI says what it did: "Drafted 3 replies".

**Do not.**
- gradient of any kind
- sparkle icons for AI
- orchid on the user's own text
- glassmorphism
