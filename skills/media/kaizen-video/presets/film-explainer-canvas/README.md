# Explainer canvas (film preset, canvas engine)

A from-scratch explainer in the look of `tiktok-explainer`: near-black with drifting light streaks, cream and orange,
Montserrat 900 headlines, Instrument Serif setup lines, Space Mono timecodes, kinetic lowercase captions and an
optional pixel mascot in the corner. It is not a slideshow: a camera pans, zooms and follows over one canvas (see
`references/canvas.md`). Sounds: whoosh on moves, pop, tick on scrubs, shutter on morphs, reveal on fills, stamp.
9:16, −14 LUFS. Worked example: `examples/canvas-film/`.
