# Notification sound sources

The ten shipped MP3 files are transcodes of Android Open Source Project Ogg sounds from `frameworks/base` commit `1cdfff555f4a21f71ccc978290e2e212e2f8b168`. They were converted with FFmpeg using `libmp3lame -qscale:a 4` for browser support. The source [Android.bp](https://android.googlesource.com/platform/frameworks/base/+/1cdfff555f4a21f71ccc978290e2e212e2f8b168/data/sounds/Android.bp) lists the originals under `frameworks_notifications_sounds` with `Android-Apache-2.0` as the default applicable license. See `LICENSE-2.0.txt`.
